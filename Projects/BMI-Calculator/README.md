# BMI Hesaplayıcı

Tkinter ile yazılmış basit bir Vücut Kitle İndeksi (BMI) hesaplama uygulaması.

## Özellikler

- Kilo (kg) ve boy (cm) girerek BMI hesaplama
- Sonucu kategoriye göre gösterme: Zayıf, Normal, Fazla Kilolu, Obez
- Kilo (2-300 kg) ve boy (30-250 cm) için sınır kontrolü
- Geçersiz girişlerde alan bazlı hata mesajları
- Enter tuşu ile hesaplama

## Çalıştırma

```bash
python3 main.py
```

Python 3 ve standart kütüphanenin parçası olan `tkinter` dışında bağımlılık gerektirmez.

## Kullanım

1. Kilo (kg) ve boy (cm) alanlarını doldurun.
2. "Hesapla" butonuna tıklayın veya Enter tuşuna basın.
3. BMI değeri ve kategorisi ekranda görüntülenir.
